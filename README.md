## 🚀 Featured Projects

### 🔵 [CronPing](https://github.com/shubhamYgit/CronPing) — Distributed URL Monitoring System
`Java` `Spring Boot` `Redis` `PostgreSQL`

Distributed cron-driven URL health monitoring with fault-tolerant worker architecture.
- **Redis `SETNX`** for distributed locking — prevents duplicate job execution across nodes
- **`BRPOP` worker pool** for reliable job consumption from monitoring queues
- **Dead letter queue + exponential backoff** for automatic retry on transient failures
- Persistent monitoring history and alert records via PostgreSQL

---
